## 一、Phase 3 完成标准

Phase 3 什么时候算做完？三个必须：

1. **Agent 能安全长期运行** — 有上下文管理、凭据脱敏、资源配额、审计日志
2. **Agent SDK 能用** — `src/agent-sdk/` 有代码，能写、注册、加载一个自定义 Agent
3. **安全体系完整** — cwd jail、AI/人类流量区分、JIT 授权、全链路集成

这三条全过，Phase 3 才算真的收尾。当前进度约 60%（#1-#7 架构组件完成，但集成和运维能力缺了一大块）。

## 四、Phase 4 主要工作

Phase 4 的核心主题：**Linux 内核级隔离**。

| 优先级 | 项目 | 说明 | 依赖 |
|---|---|---|---|
| P4-1 | **Landlock LSM 集成** | `os.landlock` ctypes 封装，限制 Agent 文件系统访问范围 | Linux 5.13+ |
| P4-2 | **Seccomp 系统调用过滤** | 限制 Agent 可用的 syscall（禁止 mount/reboot 等） | Linux |
| P4-3 | **Namespace 轻量隔离** | User/Mount Namespace，让 Agent 看不到宿主机全局 | Linux |
| P4-4 | **SandboxProvider 抽象** | 统一接口：Landlock / Seccomp / Namespace / Docker 4 种实现 | P4-1~P4-3 |
| P4-5 | **Hash-chain 审计日志** | Security Agent 的每条决策加入 hash chain，防篡改 | #3.8 之后 |
| P4-6 | **Docker 完整沙箱** | 高风险任务隔离到 Docker 容器执行 | Docker |

Phase 4 的完成标准：trimum 可以配置一个 Agent "只能读 /home/user/project 目录，只能用 git/net 系统调用，不能访问 /etc/passwd"。

## 六、决策原则

1. **Phase 3 内部串行为主**：Agent SDK → 全链路集成 → 上下文 → 可观测性，依赖链清晰，跳步会返工
2. **Phase 4 不抢跑**：Landlock/Seccomp 依赖 Linux 内核，在 Windows 上无法开发验证，必须等真机
3. **每天最多一项**：考虑到你开学了在校，建议每天专注 1 项，不堆叠
4. **穿插做快消项**：cwd jail、流量区分、错误码体系都是 <1 天的工作量，适合碎片时间搞定
