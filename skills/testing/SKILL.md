# 测试驱动

1. **先复现**：把问题写成一条会失败的测试，或先跑现有测试拿到「红」的证据 —— 没有红的证据不许改实现。
2. **小步改**：一次只改一处，改完立刻跑**目标测试文件**，不要一上来就跑全量。
3. **再回归**：目标测试绿了以后跑全量，与基线对比 —— 只许「失败集合不变」，多出一条失败就是回归。
4. **留证据**：报告里写清命令、退出码、失败条数；跑不起来就如实说「没跑成」，不许把没跑成当成通过。
